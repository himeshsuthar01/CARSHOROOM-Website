# CARSHOROOM - Car Showroom Website

A responsive car showroom website built using HTML, CSS, and Bootstrap.

## About the Project
This website showcases cars with images and provides information about the showroom.

## Technologies Used
- HTML5
- CSS3
- Bootstrap

## Features
- Home page
- Car listings
- About page
- Gallery page
- Contact page
- Car images and responsive layout

## How to Run
1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open `index.html` using Live Server.
